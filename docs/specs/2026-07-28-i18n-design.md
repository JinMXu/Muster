**日期**: 2026-07-28

## 决策摘要

| 决策项 | 选择 |
|--------|------|
| 语言检测 | 跟随系统语言，用户可在 Settings 手动覆盖 |
| 翻译范围 | 前端 ~120 条 + Rust 后端 ~18 条，全翻 |
| i18n 方案 | 手写 `useT` hook + React Context，零依赖，约 140 行代码 |

## 前端设计

### 文件结构

```
src/lib/i18n/
  context.tsx     # LanguageProvider + useT hook + detectInitialLang
  en.ts           # 英文翻译（按组件嵌套对象）
  zh.ts           # 中文翻译（结构完全一致）
  types.ts        # Lang 类型、Translations 接口
```

### useT API

```tsx
const { t, lang, setLang } = useT();

t("info.noListeningPorts")                         // 静态文本
t("git.discardConfirm", { count: 3 })             // 带插值 → "Discard 3 changes?"
t("app.unsavedChanges", { count: n })             // 复数（函数式）
```

### 语言检测

```
detectInitialLang():
  1. config.toml Settings.language 若是 "en"|"zh" → 直接用
  2. 若是 "system"（默认值）→ navigator.language.startsWith("zh") → "zh" 否则 "en"
```

### 组件改造模式

```tsx
// 前
<div>{props.name || "untitled"}</div>

// 后
const { t } = useT();
<div>{props.name || t("common.untitled")}</div>
```

字符串如 `"—"`、CSS 类名、Monaco/IExTerm 内部字符串不翻译。

## Rust 后端设计

### 翻译表

新文件 `src-tauri/src/services/i18n.rs`，`translate(key, lang) → &str`：

```rust
pub fn translate(key: &str, lang: &str) -> &str {
    match (key, lang) {
        ("no-selected-project", "zh") => "未选择项目",
        ("session-not-registered", "zh") => "会话未注册",
        // ... 18 个 key，中英双表
        _ => match key { /* 英文原词 */ },
    }
}
```

### 语言状态

`SharedState` 加 `lang: Lang` 枚举（`"en"`/`"zh"`）。  
新增 Tauri 命令 `set_language(lang: String)` 同步前端切换。

## Settings 集成

### 字段

| 位置 | 字段 |
|------|------|
| `types.ts` Settings | `language: "system" \| "en" \| "zh"` |
| `config.rs` Settings | `language: String`，默认 `"system"` |

### UI

Settings 弹窗新增下拉框：

| 选项 | 值 | 说明 |
|------|-----|------|
| 跟随系统 | `"system"` | 默认，根据 `navigator.language` |
| English | `"en"` | 强制英文 |
| 中文 | `"zh"` | 强制中文 |

切换即时生效（调用 `setLang`），Save 时持久化。

## 实施顺序

1. 前端基础设施 — 新建 `src/lib/i18n/` 全部 4 文件 + App.tsx Provider
2. Settings — 前端/后端 language 字段 + 下拉框 UI
3. 前端组件 — 逐个替换硬编码（按字符串数量从少到多，GitPanel 最后）
4. Rust 后端 — i18n.rs → SharedState → set_language → 各命令接入
5. 验证 — cargo check/test/clippy + npm run build + 手动切换验收

---

## 验收标准

- [ ] 首次启动（中文 Windows）UI 显示中文
- [ ] Settings 切到 English → 全界面即时切换为英文
- [ ] 切回 中文 → 即时恢复
- [ ] 选择"跟随系统" → 重启后仍按系统语言
- [ ] Rust 错误提示跟随语言（如创建同名文件、无效重命名等）
- [ ] 托盘菜单项（New Window / Quit）跟随语言
- [ ] `cargo test --lib` + `cargo clippy` 通过
- [ ] `npm run build` 通过

## 不翻译的内容

- CSS class 名称
- Monaco 编辑器内部 UI（Monaco 自带 i18n）
- xterm.js 终端内部文本
- 占位符字符串 `"—"`、`"(AUTO)"`
- shell 名称 `"PowerShell"`/`"cmd"`/`"wsl"`（标识符）
- Git 命令输出 / diff 内容 / 文件内容
- `aria-label` on WindowControls（图标按钮视觉已够）
